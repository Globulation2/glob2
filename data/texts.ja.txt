[AIMaxima-Profile]
基本戦略: 食料、労働者、出生、訓練、建設、戦闘を競合する需要として扱います。敵の推定戦力も考慮して軍の規模を決め、その軍を効果的に送り届けようとします。\n\n経済と発展: 食料と労働力に合わせて出生を配分し、訓練に使える余暇を残し、軍事生産が必要になると余剰労働者を増やすのを止めます。訓練能力を拡張し、改良で停止する施設が多くなりすぎないようにします。\n\n偵察と判断: 見えているユニットと記憶した目撃情報から、データに合わせて調整したモデルで敵戦力を推定します。標的は価値、距離、防衛塔、無防備な労働者、攻撃の継続性で決まります。果物任務は食事の多様性と引き抜きを支えます。\n\n攻撃と防御: 訓練と防御の戦士を確保し、適格な地上部隊を味方の食料施設の近くに集めてから波状攻撃を始めます。局所的な防御対応を行い、コロニーへの接近経路を評価します。\n\n攻撃が停滞した場合: 波状攻撃の部隊送り出しに4回連続で失敗すると、継続的に増援する攻撃用の旗に切り替えます。水を渡る攻撃でも継続的な増援を使えます。ただしこの代替策でも、集結前に生じるすべての閉塞を解決できるわけではありません。\n\n他のAIとの比較: 食料、訓練、情報、部隊展開をより密接に統合します。Cabinoが複数建物への攻撃を重視するのに対し、Maximaは必要戦力の推定と集結した部隊を送り届けることを重視します。\n\n強みと弱点: 食料の逼迫と観測した脅威に対応しながら成長と軍の補充を維持します。食料、訓練能力、開けた集結場所が必要で、混雑と長い経路は部隊の到着を妨げます。\n\n試したい対抗策: 部隊が集結する前に、手薄な小麦、食堂、兵舎を争いましょう。補給のある守備隊をまとめ、増援経路を妨害しましょう。最初の波の後も繰り返す圧力を想定しましょう。\n\n偵察: 戦力推定には隠れた敵兵の総数ではなく、目撃情報と観測履歴を使います。

[AI strategy & counterplay]
AIの戦略と対抗策
[AICastor-Profile]
基本戦略: 生産力のあるコロニーと技術に投資してから、本格的な攻撃に移ります。優先順位を付けた建設計画で集落を育て、発展、軍事施設、時間の経過に応じて戦争への備えを進めます。\n\n経済と発展: 水分、小麦の成長、障害物、労働者の到達範囲を調べます。生産と並行して食料供給の拡張、改良、防御を管理します。\n\n攻撃と防御: 健康な戦士の攻撃力を見積もり、戦力または時間の条件が満たされると攻撃します。発見済みで到達可能な建物、特に兵舎と学校を好み、価値の高い標的へ攻撃用の旗を移します。\n\n他のAIとの比較: Numbiより地形と標的の価値を慎重に考慮します。Warrushよりも辛抱強く、序盤の圧力を抑えて、発展した拠点と強い兵力を整えます。\n\n強みと弱点: 幅広い施設計画と重要な軍事目標の選択により、狙いのある攻撃を行います。ただし準備に時間がかかるため、主力が整う前に素早い相手に資源を争われます。\n\n試したい対抗策: 序盤から拡張先を争いましょう。食料だけでなく兵舎と学校も守り、発展した集落を攻める際には予備兵力を残しましょう。
[AICastor-Summary]
要塞化したコロニーを発展させ、軍事・科学施設を狙います。
[AICortex-Profile]
基本戦略: 状況に応じた優先順位で経済を育て、余剰労働力を食料、技術、軍事的圧力に回します。通常の方針は規則に基づき、学習した方針の実験には別の設定が必要です。\n\n経済と発展: 必要な人員に合わせて労働者の生産を調整し、出生を続けます。食料不足時には拡張と技術への支出を抑えます。水路の利用が有益な場合は水泳を導入します。\n\n攻撃と防御: 観測した敵の技術と利用可能な兵力から攻撃を準備します。水を渡る作戦には泳げる戦士が必要です。前線の食堂と病院で長期戦を支え、前進前に部隊を集結させることもできます。\n\n攻勢の維持と緊急事態: 小規模な嫌がらせでは何度も帰還せず、攻勢を維持します。深刻な攻撃には守備隊を呼び戻すことがあります。序盤の緊急事態では戦士だけの生産と病院の建設を始め、飢饉では小規模な決死の攻撃に出ることがあります。\n\n他のAIとの比較: Warrushより前線支援を重視します。Maximaはさらに、推定した敵戦力に対して、持続可能な出生、訓練、部隊展開を細かく配分します。\n\n強みと弱点: 攻勢を食料、治療、到達可能性と結び付けます。前線施設には補給が必要で、出生の継続は限られた食料を圧迫します。緊急時の優先順位により、成長と生存の間で取捨選択が生じます。\n\n試したい対抗策: 前線の食堂、病院、小麦を争いましょう。攻勢に対して守備隊をまとめましょう。小規模な嫌がらせでは撤退しない場合があります。\n\n偵察: 発見した敵の建物と観測した敵部隊を利用します。
[AICortex-Summary]
前線の食料と治療で、攻勢を持続させます。
[AINicowar-Profile]
基本戦略: 複数の条件を並行して判定し、成長、訓練、改良、戦争を組み合わせます。拡張しながら攻撃し、食料の供給が破綻すれば経済を立て直しに振り向けます。\n\n序盤: 同梱の攻撃的な設定では、ユニット総数が5になると戦争準備を始め、戦士が5になると戦争が可能です。レベル0の戦士も数えます。それぞれ戦士5人の攻撃用の旗を3本用意することを目指します。独自の戦略ファイルでこれらのしきい値を変更できます。\n\n経済と発展: 食料と出生の能力を増やし、労働者を訓練し、水泳と移動を発達させ、建物を改良します。食料担当の人員を調整し、飢餓に対応し、果物を求めます。\n\n攻撃と防御: 到達可能な敵建物から標的を抽選します。資源除去の旗で資源に塞がれた道を開くことができます。防衛用の旗は危険にさらされたユニットや建物の集まりを守ります。後半には地上攻撃を訓練した偵察兵が敵部隊の集団を狙います。\n\n他のAIとの比較: Warrushと同じく序盤から攻撃的ですが、その後の展開が豊富です。Cabinoと違い、病院と食堂を常に優先するわけではありません。\n\n強みと弱点: 多彩な戦術で序盤の圧力と継続的な発展を両立します。無作為な標的選択により、価値の低い建物に労力を費やす場合があります。そのしきい値にはMaximaのような詳細な敵戦力推定はありません。\n\n試したい対抗策: 早期の攻撃を想定しましょう。食料と労働者を守り、拡張を争い、高度な訓練まで進まれたら偵察兵の攻撃に備えましょう。
[AINicowar-Summary]
農業、改良、防御、偵察兵の攻撃で支える早期ラッシュ。
[AINone-Profile]
基本戦略: AIは命令を出しません。\n\n強み: 行動しないため予測しやすく、実験相手に適しています。\n\n弱点: 拡張も状況への対応もしません。
[AINone-Summary]
実験用の、何も行動しないコロニー。
[AINumbi-Profile]
基本戦略: まず食料と人口を増やし、治療、科学、訓練を加えてから戦争へ移ります。大まかな段階は相手の進歩ではなく、時間の経過で進みます。\n\n経済と発展: 人口に応じて必要な建物数を増やし、近くの小麦を見積もります。後の段階では改良、防御、拡張を加えて増大する軍を支えます。\n\n攻撃と防御: 健康な戦闘員が十分にいるか、待ち時間が切れると攻撃します。抽選した敵建物に戦闘の旗を立てます。戦力が減りすぎると攻撃用の旗を撤去し、次の攻撃のしきい値を上げます。\n\n他のAIとの比較: CastorやNicowarより予測しやすい相手です。Castorは地形と標的の価値をより慎重に考慮し、Nicowarはずっと早くから圧力をかけます。\n\n強みと弱点: 邪魔されずに発展すると幅広い支援施設が脅威になりますが、その時間割が戦況に合うとは限りません。単純な標的選択と敗北後の長い休止により、攻撃を予測しやすくなります。\n\n試したい対抗策: 軍事段階に入る前に圧力をかけましょう。攻撃の背後で食料と訓練を充実させ、襲撃を撃退した後の休止を利用しましょう。\n\n偵察: 攻撃処理は視認確認なしに敵建物の位置を直接読み取ります。
[AINumbi-Summary]
時間割に沿ってコロニーを徐々に育て、数で攻めます。
[AIEcono-Profile]
基本戦略: 労働者と偵察兵を生産し、経済を拡張し、食料と果物で敵ユニットを引き付けます。通常の戦士による攻撃は行いません。\n\n経済と発展: 小麦の近くに食堂と巣を建て、教育と移動訓練を加え、施設を改良します。食料供給を監視し、資源への立地が悪くなった古い食堂と巣を置き換えます。\n\n農業と引き抜き: 水辺の再生可能な小麦と木を守ります。偵察兵を果物の産地と敵コロニーへ送り、果物供給を求める際には敵に食料を宣伝します。良い食料と果物は引き抜きに役立ちます。\n\n他のAIとの比較: 経済に最も特化した相手です。CabinoとMaximaも果物を求めますが、軍隊と組み合わせます。\n\n強みと弱点: 軍事的な相手が消耗し合う間に成長でき、引き抜きという別の競争手段もあります。持続的な襲撃に対抗する戦士は生産しません。食料、果物、地形、勝利条件が機会を大きく左右します。\n\n試したい対抗策: 手薄な拡張先を圧迫しましょう。ユニットの離反を防ぐため、自分の食堂に食料と果物を補給しましょう。相手が成長する間、不要な戦いで自分のコロニーを消耗させないようにしましょう。
[AIEcono-Summary]
戦士を作らず、食料豊富なコロニーを育てて敵ユニットを引き抜きます。
[AIWarrush-Profile]
基本戦略: 相手が長い経済・技術開発を終える前に攻撃します。大きな支援網が必要になる前に戦闘で勝負を決めることを狙います。\n\n経済と発展: 収穫できるユニットが6になると、生産比率を労働者4、偵察兵1、戦士3にします。訓練が埋まると兵舎を追加しますが、新しい食堂は制限します。余った建設能力は病院や移動訓練に回ることが多くなります。\n\n攻撃と防御: 発見した敵建物に警備領域を設定して、戦士に継続的な圧力をかけさせます。慎重に部隊を集めた波状攻撃を待ちません。邪魔な木を除去し、一部の再生可能な資源を守ります。\n\n果物の方針: 果物採集を禁止し、果物による防御力の低下を避け、Econoの引き抜き戦略は採用しません。\n\n他のAIとの比較: NumbiやCastorより序盤の圧力を重視します。Nicowarも攻撃的に始めますが、その後はより幅広い改良と戦術を展開します。\n\n強みと弱点: 遅い立ち上がりを突き、早期の防御支出を強います。体系的な改良が乏しく食料支援も薄いため、攻勢が止まると高くつきます。地形と長距離移動は序盤の優位を損ないます。\n\n試したい対抗策: 序盤から食堂と巣を守りましょう。守備隊だけでなく労働者も補充し、訓練を進め、ラッシュが勢いを失ったら反撃しましょう。\n\n偵察: 序盤の偵察の旗は敵の開始位置を直接利用します。その後の攻撃用の警備領域の配置には視認が必要です。
[AIWarrush-Summary]
意図的に絞った支援経済を背景に、戦士で序盤から圧力をかけます。
[AICabino-Profile]
基本戦略: ユニット生産を建設、改良、防御、攻撃、探索に配分します。別々の管理役がユニットを要求・予約し、経済と軍事を一緒に発展させます。\n\n経済と発展: 幅広い集落を建設・改良し、食堂と防衛塔の人員を管理し、建物周辺を整地し、再生可能な資源を守ります。果物を偵察し、食料を宣伝して引き抜きを争います。\n\n攻撃と防御: 相手を選び、病院、食堂、兵舎の順に優先します。最大4つの攻撃を支え、通常は利用可能な兵力と近くの敵に応じて、標的ごとに戦士8～20人を割り当てます。危険な建物の周囲には別の防衛用の旗を使います。\n\n訓練: 攻撃には十分な適性のある戦士と完成した兵舎が必要ですが、最高技術までは待ちません。継続的な改良と訓練が後の攻撃を強化します。\n\n他のAIとの比較: Nicowarよりも支援施設の破壊を明確に狙います。Maximaの集結した波状攻撃より攻撃を分散し、ユニットの予約で競合する需要を調整します。\n\n強みと弱点: 成長、訓練、防御、複数の攻撃を組み合わせます。食料と治療を破壊するとコロニー全体を弱らせられます。無作為な相手選択と固定された建物優先順位で好機を逃すことがあり、複数の攻撃は兵力を分散させます。\n\n試したい対抗策: 病院と食堂を守りましょう。手薄な拡張先を争い、個々の攻撃に守備隊を集中しましょう。複数戦線を維持できるようになる前に食料か訓練を損ないましょう。\n\n偵察: 攻撃の標的選択は明示的な視認確認なしに敵の建物一覧を読み取ります。一部の経済比較は敵の統計を直接使います。

[Every colony's start is measured on the finished map, and a model fitted to thousands of games between equal opponents turns those measurements into a fitness. The fitness says how likely that colony is to win. Fairness is how evenly those chances are shared: 1 when every colony is as likely to win as any other, 0 when one colony would take the map.]

まだ学ぶことがあります。休みたいときはゲームメニューから保存し、あとで戻ってください。
[tutorial part2 message 35]
食料と身体の訓練が整いました。学校で、より良い建物に必要な技能を労働者に教えましょう。
[tutorial part2 message 36]
学校は収穫と建設の技能を高めます。建設には水中に育つ藻が必要です。泳げる労働者なら採取できます。
[tutorial part2 message 37]
大切な訓練施設を守りましょう。学校を水辺に置く必要はありません。守りやすい内陸なら攻撃を避けやすくなります。
[tutorial part2 message 38]
プールの後ろ、または巣の南西にある走路の隣など、守られた場所に学校を建ててください。空いた労働者を割り当てます。
[tutorial part2 message 39]
建物を選ぶと、割り当てられた労働者が分かります。デスクトップでは、設定可能な「ユニット経路の表示切替」で目的地への線も表示できます。現在のキーは設定のゲームコントロール欄で確認してください。学校の完成を待ちましょう。
[tutorial part3 message 1]
コロニーには食堂、病院、走路、プール、学校がそろいました。防衛の準備をしましょう。
[tutorial part3 message 2]
まだ戦士を生産していません。このままでは攻撃に対する守りが乏しい状態です。
[tutorial part3 message 3]
巣を選び、戦士の生産比率を 2 にします。労働者も生産し続けるよう、そちらは 1 のままにしてください。
[tutorial part3 message 4]
これで巣は労働者 1 人につき、およそ 2 人の戦士を生産します。速めたいなら供給する労働者を増やしてください。
[tutorial part3 message 5]
最初の戦士が生まれ、訓練を始めます。続ける前に 2 人目を待ちましょう。
[tutorial part3 message 6]
戦士も走路とプールを使います。さらに兵舎で攻撃の訓練を受けられます。
[tutorial part3 message 7]
兵舎は攻撃力と攻撃速度を高めます。攻撃力は一撃のダメージ、速度は攻撃の頻度に関わります。十分に訓練した戦士は、はるかに大人数の未訓練の敵にも勝てます。
[tutorial part3 message 8]
建設に木材を使うので、その近くに兵舎を建てましょう。
[tutorial part3 message 9]
空いた労働者を兵舎の現場に割り当てます。食料供給に十分な人数を残し、働き手の数を超える仕事を作らないようにしてください。
[tutorial part3 message 10]
兵舎が完成しました。戦士はここで攻撃技能を鍛えられます。
[tutorial part3 message 11]
建物をアップグレードするとコロニーを強くできます。
[tutorial part3 message 12]
学校で訓練した労働者はアップグレード工事ができます。対象の建物を選び、建物の操作で「改良」を探してください。傷んだ建物は先に「修理」が必要なことがあります。
[tutorial part3 message 13]
最初に何を上げるか考えましょう。食堂はまだ余裕があるので、あとで構いません。
[tutorial part3 message 14]
病院にも空きがあります。学校、走路、プール、兵舎に集中できます。
[tutorial part3 message 15]
まず走路をアップグレードして、さらに速く移動できるようにしましょう。
[tutorial part3 message 16]
走路を選び、建物の操作から「改良」を選びます。中のユニットが出てから工事するため、すぐに変わるとは限りません。
[tutorial part3 message 17]
空いている労働者を走路の工事に割り当てます。レベル 2 の現場を建設できるのは、必要な学校の訓練を終えた労働者だけです。
[tutorial part3 message 18]
走路のアップグレードが終わるのを待ちます。高レベルの建物ほど資源と工事時間が必要です。
[tutorial part3 message 19]
レベル 2 の走路が完成しました。以前より広くなったので、隙間を空けておいたのです。拡張する場所が足りなければアップグレードできません。
[tutorial part3 message 20]
次は兵舎とプールをレベル 2 にしてください。両方完成したら続けます。
[tutorial part3 message 21]
アップグレードした建物は通常、利用人数や訓練の質が向上します。たとえばレベル 2 の食堂は席が 7 つあり、基本の食堂より速く食事できます。
[tutorial part3 message 22]
敵が近くにいます。攻撃に備えましょう。
[tutorial part3 message 23]
塔は射程内の敵を撃ち、壁が塔を守ります。両方を使って、コロニーへの狭い通路を防衛します。
[tutorial part3 message 24]
場所があれば塔を 2 基ずつ置きます。壁で三方を守りつつ、労働者が石の弾薬を運ぶ通路を残してください。
[tutorial part3 message 25]
プールの東、ほかの果樹の北を見てください。別の島へ続く狭い渡り口があり、防衛に適しています。
[tutorial part3 message 26]
木と岸の間に塔 2 基分の場所を考えます。後ろには石の配送路、ほかの側には壁の場所を残します。労働者を壁で締め出さないでください。
[tutorial part3 message 27]
そこに塔を 2 基建てます。画面の利用可能人数を見て、各現場に労働者を 2～3 人割り当ててください。
[tutorial part3 message 28]
建物の操作で、塔の外向きの三方に壁を置きます。コロニー側は労働者が通れるように空けておきます。
[tutorial part3 message 29]
壁 1 区画ごとに建設の仕事ができ、石 1 が必要です。人数が足りなければ、順番に完成させられます。
[tutorial part3 message 30]
塔 2 基と壁の数区画が完成するまで待ちます。塔には石の弾薬も必要ですが、採石場が遠いため配送は遅くなります。余った労働者がいれば塔の目標人数を増やしてください。
[tutorial part4 message 1]
食料、訓練、防衛が整いました。建物はさらにレベル 3 にでき、訓練や収容人数が向上します。資源と労働者の技能に応じて改善を続けましょう。
[tutorial part4 message 2]
拠点の北西で敵のコロニーを探してください。今そこへ視点を移してください。
[tutorial part4 message 3]
探索済みの地形も戦場の霧で隠れることがあります。敵の現在の動きを見るには、近くに探検家が必要です。
[tutorial part4 message 4]
「旗」を開いてください。旗と領域を使えば、個々のグロビュールを直接操作せずに指示できます。
[tutorial part4 message 5]
凧形の印がある偵察の旗を選びます。旗は陸、水、資源、未探索の地形にも置けます。
[tutorial part4 message 6]
敵の拠点と思われる場所に偵察の旗を置きます。おおよその位置で偵察を始められます。右クリックで配置を抜けるか、タッチ操作で配置を完了してください。
[tutorial part4 message 7]
旗の周りの輪郭が活動範囲です。割り当てた探検家がその範囲を偵察します。来なければ人数を確認し、必要なら巣で増やしてください。到着したら Space または「OK」で進みます。
[tutorial part4 message 8]
敵には多くの労働者と集結した軍隊がいます。攻められる前に守りを固めましょう。
[tutorial part4 message 9]
「旗」を開き、青い警備領域を選びます。取り除くのではなく、範囲を追加するモードを使います。タッチ画面では「消す」でなく「描く」を選んでください。
[tutorial part4 message 10]
ブラシの形と大きさを選びます。大きな正方形は、まとまった防衛範囲を作るのに便利です。
[tutorial part4 message 11]
敵が来そうな塔のすぐ後ろに警備領域を塗ります。クリックやタップで 1 か所、ドラッグで広く塗れます。タッチ画面で塗っている間に視点を動かすには「移動」を使います。
[tutorial part4 message 12]
空いている戦士が警備領域に集まります。全員が入れて、かつ渡り口に集中できる程度の大きさにします。攻撃を待ちましょう。
[tutorial part4 message 13]
敵が渡り口に近づいています！
[tutorial part4 message 14]
攻撃を受けています。訓練した戦士と塔が陣地を守る様子を見ましょう。
[tutorial part4 message 15]
守り切りました！「旗」を開き、とげのある戦闘の旗を選びます。敵の巣に置いて、そこへの攻撃を指示してください。
[tutorial part4 message 16]
配置モードを抜け、戦闘の旗を選びます。戦士を 2 人以上割り当て、半径を縮めて敵の巣の周りに攻撃を集中させます。戦士の到着を待ちます。
[tutorial part4 message 17]
攻撃が始まりました。敵の巣に着くには、塔を突破しなければなりません。
[tutorial part4 message 18]
戦士が敵の拠点に到着しました。巣への集中攻撃を続けてください。
[tutorial part4 message 19]
敵の巣を破壊しました。おめでとうございます！チュートリアルを終え、食料供給、割り当て、訓練、アップグレード、偵察、戦闘の基本を学びました。
