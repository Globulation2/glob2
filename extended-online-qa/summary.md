# Extended Bulgarian online QA

Technical visual QA in Playwright Chromium, desktop 1280×900 and phone 390×844, bg-BG plus explicit Bulgarian cookie. A private real API fixture server ran on 42769 with a separate disposable PostgreSQL fixture on 42770; no real provider, payment or email action occurred.

64 initial captures: 42 gallery/player/leaderboard/match/account/studio/invite views, 14 upload/detail/error views, two actual building-family editor views created through the fixture API, and six populated AI/terrain/music galleries using the existing libraries.spec.ts list-response fixtures. Main/form/editor reports and full screenshots are adjacent. Six mocked populated galleries are clearly identified in populated-report.json. All initial captures were reviewed in sheet-1.jpg through sheet-4.jpg; the editor was also inspected at full size.

Ten phone views had document overflow of 12–169 pixels. Three CSS changes fix the causes: translated content buttons wrap within their column, intrinsic form-control minimums can shrink, map-preview action rows wrap, music form grids use zero minimum tracks, and profile summary tables keep their ellipsized name column within the card. Sidebar/navigation controls are outside the shared button rule. No translated values or simulation code changed.

58 subsequent real-API captures show zero document overflow and no measured interactive controls outside the viewport; Bulgarian font loaded in each view. responsive-results.json contains every before/after overflow value. Original screenshots remain untouched, with before-manifest.json and after-manifest.json SHA-256 evidence. css-build-manifest.json identifies the produced CSS and entry bundle. The after/responsive-inspection.jpg crops were inspected directly: long actions wrap legibly and file fields fit.

The new localized-layout.spec.ts tests the ten affected routes at phone and desktop widths, including an actual fixture-created editor. Its first run passed (1 test, 20 route/viewport checks, 1.9 minutes). A second run with an explicit heading-ready assertion also passed (1 test, 20 checks, 1.8 minutes), recorded in responsive-test-final.log. Final CSS source narrows the profile-table selector from all card tables to the actual grid3 WinRates cards; root must include that narrower selector in its final product build/validation. Vite CSS build passed in 42.90 seconds; Prettier passed.

Remaining source gaps were reported to root for separate fixes and translation review: canonical AI tags rendered raw in filter/card/detail paths; map visibility options displayed raw strings; MusicCreate capitalized metadata field names instead of translating them. Current screenshots precede root's final build for those fixes. Proper user, map, queue, AI and uploaded asset names remain unchanged. Automatically generated editable draft names were flagged separately; they are not retroactively rewritten.

Coverage limits: AI/map/music studio and skins routes returned their localized unavailable state under this fixture configuration; their full provider-backed editing and payment flows were not exercised. Building-family editing and terrain-set authoring UI were exercised. The online room workflow covered the actual valid and missing server-rendered invite pages and their launch controls, without launching an external installed application or a WebAssembly multiplayer room. Browser-owned file chooser captions appear in the headless Chromium installation's language; this is outside the application's catalog. This is agent technical QA, not a native-human linguistic certification or Safari/Firefox/mobile-device signoff.

Cleanup: stopped the private 42769 API process and removed only glob2-bulgarian-extended-qa (42770 PostgreSQL). Other servers and containers were not stopped or reconfigured.
