# Contributing to Globulation 2

The shared [contributor and coding-agent guide](AGENTS.md) contains the repository
map, build/test entry points, engine verification requirements, and review/merge
ownership. `CLAUDE.md` is a symlink to that same file, so all contributors and agents
use one source of instructions.

Engine, architecture and gameplay proposals are welcome. Explain the problem and
tradeoffs, keep unrelated changes separate, and use the guide's evidence and review
requirements when preparing a PR.
