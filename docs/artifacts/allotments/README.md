# Allotments revision 2 review previews

Villages among allotment gardens: warped parcels of strip plots round ditches, each plot tended differently, commons round ponds and woodlots; every village an open green behind its own plot block. The design, controls and checks are in the
[framework document](../../map-generators/MAP_GENERATOR_FRAMEWORK.md).

Rotation tournaments (six 256x256 maps, four colonies, every cyclic rotation, 45,000 ticks,
revision 1 then revision 2 candidates, per colony-game): Nicowar: peak 118 to 100, births 82 to 97, eliminations 18 to 12 of 96 (village plots four wide). Numbi with nine-wide village plots: peak 31, births 27, eliminations 2 of 96. The later changes (Numbi
fixes, one facing per map) passed the shape sweeps, contract tests and golden rows but no
further tournament; a maintainer's playtest is the next evidence.
