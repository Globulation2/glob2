# Contributor tools

Start with the domain guide for the behavior you want to change. These tools
support evaluation, content production, and validation across domains.

## Main executable

- [Glob2 CLI](cli.md): command discovery, workflows, completion, and migration.

## Evaluate games and AI

- [Distributed tournaments](tournaments.md): schedule games and collect results.
- [AI development and evaluation](../ai/README.md): opponents, telemetry, and models.
- [Map-generator tooling](../map-generators/README.md): generation, rendering, and fairness studies.
- [Maxima test fixtures](../../test/maxima/README.md): focused AI regression evidence.

## Create assets

- [Asset workflows](../assets/README.md): artwork, terrain, and music.
- [Unit-animation renderer](../../tools/unit-animation/README.md): preserved Blender sources and pose export.
- [Artwork tools](../../tools/artwork/ai/README.md): reviewed production inputs and packaging.

## Validate changes

- [Test entry point](../../test/README.md): choose focused checks and fixtures.
- [Lobby automation](../development/testing/lobby-automation.md): native client UI testing.
- [Documentation maintenance](../development/documentation.md): local links, anchors, navigation, and factual review.

The [tools directory](../../tools/README) indexes its build, asset, geography, and legacy sprite utilities.
