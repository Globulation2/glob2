# Assets and content production

Assets need reproducible sources, clear attribution and validation in the game.
Start with a workflow, then follow the reference for the asset family you are changing.

## Workflows

1. [Content quick start](content-quickstart.md): maps, definitions, scripts and packages.
2. [Artwork production](artwork-workflow.md): preserve sources, stage, review and package.
3. [Terrain materials](terrain-materials.md): catalog bindings and visual authoring.
4. [Music pipeline](music-pipeline.md): build and validate soundtrack sets.
5. [Soundtrack style](music-style-guide.md): composition and game-feel guidance.
