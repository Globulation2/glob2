# Scripting

Write custom AI controllers and map scripts in JavaScript. Runtime code executes JavaScript; the editor declarations help authoring without introducing a TypeScript build step.

1. [Author, install and debug a script](javascript.md).
2. [Look up the API contract](javascript-api.md).
3. [Run scripting verification](../development/testing/scripting.md).

[Examples and editor declarations](../../examples/javascript/) accompany the API. Scripts execute embedded trusted code, operate on immutable observations, and return validated intents. Read the guide’s determinism and persistence requirements before adding a controller.
