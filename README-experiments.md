# Rejected and held CPU-offloading experiments

Production source remains `348f087b31ad20df0b4c5d5ef7ae40a1b46d8986` for these comparisons. None of these experiments qualifies resident preparation or a new backend/platform. All comparison runs use frozen inputs, full release builds, shadow verification and diagnostics off, eight alternating pairs, and complete process user plus system CPU including startup and exit. Extract alongside the preceding `evidence.tar.gz` for the nine original save inputs and dependency receipts. Binaries and tool environments are excluded; executable hashes and source revisions identify them.

- Combined Vulkan uploads (`7a96ad2ee79ab025cc7995696c76cecb5f8f1ac3`, draft PR #1167): rejected. Whole-process cohort CPU savings -0.749%, paired 95% interval [-2.456%, +0.957%]. River 128 late has 7.04% CPU regression, interval [4.21%, 9.86%]; river 256 late has 11.99% regression, interval [7.90%, 16.08%], and 12.85% median whole-process elapsed regression. GPU commits rose from 26,874 to 30,254; that is execution coverage, not CPU savings. Hardware correctness, synchronization validation, golden traces and byte-identical save continuations passed. Separate ranges need a larger charged staging allocation.
- CPU clearing lookup: rejected. Callgrind instructions rose 40.86%; whole-process CPU regressed 0.703%, paired 95% interval [0.367%, 1.039%].
- Captured farming specialization: held, not enabled. Callgrind preparation instructions fell 2.21%, but whole-process CPU savings were 0.160%, paired 95% interval [-0.677%, +0.996%]. Six reference-contract cases / 36,982 assertions and 28 isolated preparation cases passed.

These are nine Castor changing-world candidate saves, not the complete audited material/clearing qualification cohort. Compute count is eight for GPU upload comparisons and one for CPU preparation comparisons. Publication-wait p95, other counts and backend/platform qualification are incomplete. Callgrind is diagnostic only; native paired runs decide CPU outcomes. See archive manifests, raw run results, commands, checksums, saves, profiles and decision JSON for reproducibility.
