Memory accounting caveat
OpenCLHostBudget64MiB,OpenCLDeviceBudget128MiB (OpenCLGradient.h12–13) bound REPOSITORY-OWNED metadata,request/input graphs,CPU staging,cost planes and cl_mem payload sizes. Driver shared-library mappings,CUDA context/JIT/compiler heaps,command-queue internals and driver device allocations are not comprehensively charged by these budgets. Host peakRSS can greatly exceed accelerator_peak_host_bytes without violating payload budget. VRAM/nvidia-smi memory is a separate measure; peakRSS is host resident RAM. Sparse/few GPU dispatches can still pay initialization memory.
A GPUon>=2thread run may hold driver/context memory before first useful field. A1thread run skips service initialization entirely, so comparing1threadGPUon vs32threadGPUon confounds worker storage with driver initialization. Matched worker countGPUoff/on is necessary.
