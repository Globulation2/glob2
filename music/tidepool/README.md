# Tidepool

A Caribbean-inspired 32-bar score in 4/4 at 100 BPM, with steel drums, offbeat organ,
electric bass and hand percussion. D minor → B-flat → F → C supports the recurring
two-bar hook. Calm spaces out the melody and percussion; building has the full
one-drop groove; combat lowers the hook an octave with wood doubles, a punchier
bass rhythm and strong backbeat. All moods share harmony and timing over 76.8 seconds.

`generate.py` exports the three editable MIDI arrangements. Render with `python3
music/render.py tidepool`, then install using `python3 music/install_sets.py tidepool`.
See `music/README.md` for the shared FluidSynth workflow. Save DAW edits separately
before regenerating MIDI files. Render statistics include preview transition times.
