# Bramble Dance and Velvet Orbit

Bramble Dance is a 40-bar marimba and bamboo-flute score in 6/8 at 108 quarter-note
BPM. Combat uses low marimba runs and stronger hand percussion. Velvet Orbit is a
24-bar score in 4/4 at 72 BPM, with electric piano, glass tones and pads; combat
adds a heavier broken beat and synth bass.

`generate.py` exports calm/building/combat MIDI files for both sets. Each trio has
aligned notes and harmonic positions. Render with `python3 music/render.py
bramble-dance velvet-orbit` using the shared Apple sampler workflow documented in
`music/README.md`. MIDI files remain editable in a DAW; save edits separately before
regenerating. Audio and preview statistics are generated by the shared renderer.
