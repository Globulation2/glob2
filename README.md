# Bulgarian localization evidence (preparation snapshot)

This is a curated partial preparation snapshot while final builds run. Active logs are frozen at their first read and may be incomplete. V4 review proof and independent binding validation are included. Final runtime captures and gate binding are pending. Historical files retain their own source/catalog identities; the preparation revision does not rebind an older check.

- `translation-review.tar.gz`: frozen translation kits, raw provider requests/responses and cumulative spend ledger, rejected mapping evidence, role reviews and binding proofs.
- `implementation-review.tar.gz`: reviewed implementation patches, staged source/test inputs and focused syntax/probe evidence.
- `verification-logs.tar.gz`: bounded check/build logs, inventories, JUnit results.
- `render-diagnostics.tar.gz`: large lossless diagnostics from explicitly curated captures.
- Native and browser screenshots and concise QA reports remain directly browseable.
- `frozen-inputs.json` binds every original input label to its immutable scanned snapshot.
- `archive-members.json` lists every archive member with size and SHA-256; `manifest.json` binds publication files.
- `embedded-image-omissions.json` records metadata/hashes for duplicate screenshot bodies removed from JSON reports. Original local evidence remains unchanged.

No binaries, dependency trees, build outputs, synthetic account profiles, caches, or provisional online reports are included. Language reviews are agent reviews, not native-human certification. Untested platform/rendering gates remain pending.
