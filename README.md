# Globulation 2

[![Build status](https://github.com/Globulation2/glob2/actions/workflows/build.yml/badge.svg?branch=master)](https://github.com/Globulation2/glob2/actions/workflows/build.yml)

Globulation 2 is a real-time strategy game in which autonomous units carry out
your priorities. This repository contains the game engine, native and browser
clients, content tools, and the online multiplayer platform.

## Play

Visit [glob2online.com](https://glob2online.com/) for downloads, gameplay guides,
and community information. Play in your browser or use the online app at
[app.glob2online.com](https://app.glob2online.com/).

## Build and contribute

Start with [Contributing](CONTRIBUTING.md), then follow the
[development guides](docs/development/README.md) for your platform. Routine builds
use `python3 tools/dev_build.py`; prerequisites and platform options are in the
build guide. [Testing](test/README.md) explains how to choose and run checks.

Explore the [documentation library](docs/README.md) for architecture, gameplay
features, AI, maps, assets, scripting, multiplayer, hosting, and releases.
[AGENTS.md](AGENTS.md) records shared compatibility and review requirements for
human contributors and coding agents.

## Operate and release

[Hosting](docs/hosting/README.md) covers running an online instance, maintenance,
and recovery. [Releases](docs/releases/README.md) covers packaging and distribution.
For problems, see [Support](SUPPORT.md). Code and asset notices are indexed in
[Licensing](docs/development/licensing.md).

## Related projects

The public website lives in the separate
[glob2-online-website repository](https://github.com/Globulation2/glob2-online-website).
Its [content guide](https://github.com/Globulation2/glob2-online-website/blob/main/docs/content.md)
and [hosting guide](https://github.com/Globulation2/glob2-online-website/blob/main/docs/hosting.md)
cover that site's independent publishing process. The
[original wiki](https://globulation2.org/wiki/Main_Page) contains historical
material and older translations.
