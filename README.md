# Evidence: colony-skin material system rework

Review images for the `skin-material-catalogue` branch (commit 46e5a815d, after the
art-direction and code review pass). `before/` holds the first revision (e630a7810).

- `native-contact-sheet-4x-materials-*.png`: the same tiles, nearest-upscaled 4×.
- `native-worker-matte-hairy-woven-leather-carbon-cloud.png`: worker tiles at 4× for the materials whose micro grain used to alias at game scale.
- `studio-swatches.png`: the Colony Studio material picker (grouped strips, one shared WebGL context).
- `studio-worker-all-materials.png` and `studio/desktop-worker-<key>.png`: the worker filled with each material at studio resolution, from the `skins-materials.spec.ts` e2e.
- `material-fingerprints.json`: the committed appearance fingerprints generated by the native test.
