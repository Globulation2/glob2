## Result and scope

Optional video libraries are libvpx 1.17.0 and libaom 3.15.1; Opus is the existing native client dependency. Two independent reviews found no remaining actionable issues after AV1 header-order, native Opus ownership/cache, chronological journal and fixture-timing fixes. See reviews.md.

All three final development client, unit-test and engine-test targets built successfully on the source revision above. These use `tools/dev_build.py`, `CC=cc CXX=c++`, `-j16`, the selected recording profile and explicit `unit-tests engine-tests build/<profile>/src/glob2` targets. SDL and recording prefixes were supplied through `GLOB2_SDL3_PREFIX` and `GLOB2_RECORDING_PREFIX`; exact compiler/link commands are in the compressed build logs. SDK receipts and source/license notices are in receipts/ and verification.json.

## Dependency and coverage limits

libvpx uses BSD licensing plus its patent notice; libaom includes BSD licensing and AOM patent terms. Both optional source releases are checksum-pinned. This is the codec addition requested and approved by the maintainer. Local static video archives measure 2,536,698 bytes for libvpx and 10,790,490 bytes for libaom; these are build-input sizes, not installed package deltas. Full per-library sizes, compiler inputs and source receipts are in verification.json. No second Opus archive is bundled.

Executed locally on Linux x86_64 only. Windows, macOS, mobile, browser and ARM execution, release packaging, representative performance measurements and maintainer playtesting are not claimed by this evidence.
