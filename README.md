- `studio-swatches.png`: the Colony Studio material picker (grouped strips, one WebGL context).
- `studio-worker-all-materials.png` and `studio/desktop-worker-<key>.png`: the worker filled with each material at studio resolution, from the `skins-materials.spec.ts` e2e.
