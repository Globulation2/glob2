# Persistent JavaScript globals review evidence

Source: `96f4537891928f86e82093c90af8172136012d32`, PR [#478](https://github.com/Globulation2/glob2/pull/478). Generated evidence is separate from the source branch. Previous second-pass evidence at `8024750c0b47ffbbc7bfd46d345511f77107f25c` applies to its earlier revision; these archives rerun the corrected persistent runtime and draft fixtures.

Scripts now use ordinary top-level variables and `step(ctx)` or `main(ctx)`. Automatic graph snapshots preserve supported global data across callbacks and save/load. Callback rejection rolls back globals, RNG and effects. Source functions may close over top-level bindings and are recreated on load; private closure locals, classes, opaque objects, accessors and function-owned state are rejected explicitly. The scripting guide documents the boundary. Realistic AI/map scripts read actual engine observations, calculate economic/resource metrics, retain results in globals and execute legal orders. Numeric and realistic returned-data goldens remain unchanged; draft simulation fixtures change for the new source and snapshot representation. Released formats and behavior remain compatible.

The 14 platform archives retain successful execution on this same clean revision: macOS ARM64 and Rosetta x86-64; Linux GCC 13, GCC 15 and Clang 18; Chromium, Firefox and WebKit; both ARM64 and ARMv7 on physical Acer Android 7/API 24 and Samsung Android 16/API 36; an explicitly selected API 35 Android x86-64 emulator on devlaptop; and iOS ARM64 Simulator. Each records source/build/fixture/executable metadata, commands, logs, numeric results/data, complete per-tick traces, saves and replays. Every comparison in `validation.json` is acceptance-eligible: all 44 shared artifacts agree. Decoded cross-platform saves exclude only the 20-byte MapHeader SHA1. Same-platform worker/replay/save equality is checked before that normalization.

Extract archives and compare from the matching source checkout, for example:

```sh
python3 test/check_javascript_evidence.py macos-arm64-96f453789 browser-chromium-96f453789 --output comparison.json
```

`released-and-cli.tar.gz` retains released non-JavaScript traces and v108 continuation on both macOS architectures and all three Linux compiler configurations, both 256-tick CLI scripting fixtures with exact one/four-worker output and six continuation checkpoints, and three browser 1500-tick traces equal to native bytes. Fresh released traces compare complete checksums; v108 continuation compares every stored team/entity record, excluding its version-dependent aggregate. Actual legacy fixtures are v88/v108/v121; minimum save version 58 is checked as a constant, but no historical v58 fixture was available. The accepted released v123 replay executes and replay/network acceptance boundaries are tested. Additional GCC 11, GCC 13 and Clang 18 CI evidence also matches all 44 artifacts.

`builds-and-diagnostics.tar.gz` retains full/incremental build logs and configuration, portable-compiler regressions, vendor reconstruction, ordinary test-runner and save-safety results. Final affected objects were rebuilt. The ordinary runner passes 27 jobs/41 cases plus one save-safety case. Vendor reconstruction reproduces 22 QuickJS and 70 OpenLibm files. `source.bundle` contains changes relative to original PR head `147a99f66dcd2f2d814c1f4e409686f49551f6d6`; fetch that prerequisite before fetching the bundle. `SHA256SUMS` verifies the archives and manifests.

Incomplete gates remain: execution inside the existing Windows Vagrant VM awaits restart approval after its internal failure (reset could discard unsaved VM state); physical iOS needs Xcode account/profile and a paired, unlocked normal-mode device. Simulator evidence does not replace that run. [Latest-revision CI](https://github.com/Globulation2/glob2/actions/runs/36840997720) and fresh independent maintainer review are outstanding at packaging time.
