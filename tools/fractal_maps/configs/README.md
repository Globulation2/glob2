# Practical completion checks

These are inputs to the existing tournament `Planner`, with stable generator IDs
34 (Gardens) and 35 (Hilbert), candidate selection disabled, and explicit seeds.
The opening checks use 20,000 ticks, not the original 90,000-tick tournament cap.
Each AI configuration expands both maps into complete two-seat rotations.

```python
import json
from pathlib import Path
from tools.tournaments.bundles import inspect_bundle
from tools.tournaments.experiments import Planner

bundle = inspect_bundle("artifacts/fractal-maps/bundles/BUILD_ID")
config = json.loads(Path("tools/fractal_maps/configs/opening-econo.json").read_text())
manifest = Planner("fairness", config, [bundle]).plan()
Path("opening-econo-plan.json").write_text(json.dumps(manifest, indent=2) + "\n")
```

Use `generator_stress` for `default-seeds.json`, and `fairness` for either opening
configuration. Submit the resulting immutable manifest with `tools.tournaments`.
`tools.fractal_maps.plan` retains the larger original matrices and all-AI cohorts.

The final bundle's bulk plans are generated by `tools.fractal_maps.plan`. In
addition to that 128–512-tile, 2–8-colony matrix,
`registered-edges.json` checks the exposed 64-tile and one/twelve-team control
edges. They are outside the agreed playable target and should receive explicit
rejections. `tools.fractal_maps.bulk_inspect` reads committed tournament results
from all cohorts, compares effective controls after filling defaults, and flags
missing reports, disconnected land, inaccessible starter supplies, unprotected
service courts, small expansion catchments, and unusually poor soft scores. It
performs no additional game simulation or map scan.
