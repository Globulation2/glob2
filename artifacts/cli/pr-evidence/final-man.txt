[1mNAME[0m
       glob2 - Globulation 2 game and tools

[1mSYNOPSIS[0m
       [1mglob2 [22m[COMMAND] [OPTIONS]

[1mDESCRIPTION[0m
       Without  arguments,  launches  the game. Use glob2 help COMMAND for de‐
       tailed help.  Use glob2 help --format json for the self-describing  CLI
       schema.

              Type: enum.
