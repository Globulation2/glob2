# Sixteen-team implementation validation

The live colony/controller cap is 16. The five extended generators accept 13–16 only on 512×512; previous supported map fingerprints are unchanged. Disk header slots remain 32, save floor remains 58, new saves use 127, replay floor is 127, and network/YOG gates are 50. Custom-game preferences version 4 reads historical versions 1–3 with twelve colony records.

## Checks and evidence

- Native release client, generator tools, engine tests and unit tests built under `build/team-limit`; serial WebAssembly built under `build/team-limit-web`. These isolated build roots preserve unrelated workspace work.
- Unit suite: 393 cases, 391 passed, two skipped (`tests-unit-final/junit.xml`). One timing benchmark failed during the initial heavy sweep; both its isolated retry and the full final suite passed without changing its bound.
- Core team/save/script/replay/protocol/Maxima suite: 45 cases, 44 passed, one display case skipped; separately covered by the display suite (`tests-core-complete/junit.xml`).
- Six display cases passed (`tests-display-complete/junit.xml`), including lobby team 16, editor selection/save/load and 16-team statistics. Lobby and editor PNG captures are under that directory.
- The committed genuine pre-127 fixture was generated by an actual twelve-slot format-126 binary: four Maxima controllers, EvenGround, map/game seed 7, 256×256. The legacy save loads, advances and survives a new-format re-save.
- Training seeds 1–32 and held-out seeds 20001–20032: all 1,280 default generation cases passed final validators, five generators × four counts (13–16) × 64 seeds (`generation/matrix/summary.json`).
- All 176 control endpoint cases completed successfully. One Portage Lakes wheat-amount=0 held-out seed 20001 exceeded the initial 180-second limit; the exact retry succeeded in 221.8 generation seconds, and profiling repeat succeeded in 162.0 seconds with the same fingerprint. No validator or retry budget was loosened. Details under `generation/controls/portage-lakes-wheat-amount-0-20001/`.
- All 564 actual macOS ARM64 golden rows matched (`golden-check.log`). Existing supported cases for the five changed generators have identical status/hash to HEAD. Only actual macOS rows were regenerated; foreign-platform rows were preserved.
- Five mixed-AI games (Maxima/Nicowar/Warrush/Castor repeated four times), seed 271828, completed 4,096 ticks with all 16 teams still alive (`matches-fixed/*/{command.json,result.json,initial.game.gz}`; Gauntlet also includes the final save). These verify stability and opening economy, not full-match balance.
- A real full-array enemy iterator bug was fixed after these matches initially exposed an out-of-bounds null-sentinel scan. A regression covers all 15 enemies, only enemy 15 and no enemies.
- Native one-worker, native four-worker and serial WebAssembly traces match byte-for-byte for the same saved 16-team game, seed/orders and 512 ticks. Files under `checksums/`; SHA-256: `df72e373f341480d9ddc7ef8e9e8059e663bb97401c2f3a2bd39efa2d8f3846f` (12,068,696 bytes each).
- Translation key audit: all five checks passed (`translations.log`). Source/test/documentation diff whitespace check passed.

## Coverage limits

Linux, Windows, mobile and threaded WebAssembly execution/checksums were not verified locally. Updated generator golden rows still need actual foreign-platform generation. A live lobby with sixteen separate remote clients was not exercised. Maintainer play review is still needed for pacing/density; Warrush’s capacity-derived opening window now lasts 32 rather than 24 ticks even in smaller matches. Extreme Portage Lakes controls can be slow. Existing unrelated browser/deployment/threading edits were preserved.
