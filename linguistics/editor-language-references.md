# Independent Bulgarian editorial references

AI editorial research, accessed 2026-10-31; not native-human certification.

- BERON, official Bulgarian orthographic dictionary, https://beron.mon.bg/rechnik/491 : count forms follow numerical quantity for masculine nonperson nouns; ordinary plural appears when an intervening preposition or verb separates numeral and noun. Person-denoting nouns retain ordinary plural. Apply consistently to играчи, работници, воини; use e.g. 2 файла and 2 мача for inanimate masculine nouns. Treat fictional roles as person-like labels per project glossary.
- European Commission Bulgarian translator style guide, https://commission.europa.eu/document/download/468ff0a1-eb68-4d61-8bc1-c40bdff61ade_bg?filename=Bulgarian+Style+guide_0.pdf : search-index excerpt read on masculine full/short articles. Subject takes full article; object/prepositional complement takes short article. This is particularly relevant to errors such as „Изберете отборът“.
- Microsoft Bulgarian product documentation, https://support.microsoft.com/bg-bg/accounts-billing/manage/what-is-a-microsoft-account : contemporary primary software usage supports акаунт, настройки, влизане, хронология. These are descriptive terminology references, not Bulgarian orthographic authority.
- Microsoft Bulgarian software instructions, https://www.microsoft.com/bg-bg/microsoft-365/business/how-to-use : instructions use plural imperatives e.g. Въведете, Изберете; labels include Свързване and Промяна. Follow project's plural-address and concise noun-action policy.
