# Support and issue reporting

Use the [Globulation 2 issue tracker](https://github.com/Globulation2/glob2/issues)
for reproducible bugs, contributor questions, and proposals. Search existing
issues before opening a new one. Player guides and community information are on
[glob2online.com](https://glob2online.com/).

## Report a problem

Include your game version, operating system and architecture, the steps to
reproduce, expected behavior, and what happened. For a source build, include the
commit and build options. Attach relevant logs and a minimal map, save, replay,
or screenshot when it helps reproduce the problem.

Remove credentials, tokens, personal information, and private instance details
from attachments. Public issues are visible to everyone. This repository does
not document a private vulnerability-reporting contact or a response-time promise.

## Troubleshoot and contribute

Start with the relevant [documentation topic](docs/README.md): development for
build/test failures, browser or mobile for platform issues, multiplayer for
connection behavior, and hosting for instance operations.

See [Contributing](CONTRIBUTING.md) to prepare a fix or propose a change.
